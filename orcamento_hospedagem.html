Orçamento e hospedagem

Quanto custa manter o TERS no ar e por que escolhemos o GitHub Pages para publicar o site.

Onde o site está publicado

O TERS está no GitHub Pages, no endereço fabricio342gp.github.io/U-UNICID-ADS-CC-ENG-FRONTEND-2260016-D4-2-2026-M-TERS.

Hospedagem é o serviço que guarda os arquivos do site e os entrega a quem abre o endereço. O GitHub Pages publica os arquivos direto do nosso repositório: cada vez que a equipe envia uma mudança para a branch principal (main), o site é atualizado.

Por que escolhemos o GitHub Pages

  • Custo zero: o projeto não tem verba, e o serviço é gratuito para repositório público.
  • Segurança: o endereço já abre com HTTPS, sem configurar nada.
  • Simplicidade: o código e o site ficam no mesmo lugar. Quem envia uma mudança para o GitHub já atualiza o site.
  • Combina com o TERS: o site é estático e não precisa de servidor nem de banco de dados.
  • Plano B: se um dia o formulário precisar enviar mensagens de verdade, aí será preciso um servidor, e o plano Hobby do Railway (US$ 5 por mês) volta a ser uma opção.
